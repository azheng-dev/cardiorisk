# `reports/v1/drift/` — Phase 2.6 drift / monitoring outputs

Generated by `backend/scripts/compute_drift.py --full` against
`data/processed/combined.parquet` and the calibrated artefacts under
`models/v1/`. Layout:

```
reports/v1/drift/
├── README.md                              (this file, committed)
├── per_fold.json                          (16 cells: 4 models x 4 LODO folds)
├── aggregate.json                         (cross-fold severity tally + prediction-PSI per model)
└── smoke/                                 (CI smoke output; gitignored)
```

Plus 16 dashboard PNGs (one per model x fold) under
`reports/v1/figures/drift/<model>_<source>_dashboard.png`.

## What gets committed

The full-run JSONs + dashboard PNGs are committed so the repo is a
self-contained record. Smoke-mode outputs (`drift/smoke/`) are
gitignored.

## Schema — `per_fold.json`

A list of 16 cells (4 models x 4 LODO folds). Each cell:

```json
{
  "held_out_source": "Cleveland",
  "model": "tabicl",
  "n_current": 303,
  "compute_seconds": 5.7,
  "severity_counts": { "stable": 4, "moderate": 2, "major": 5 },
  "per_feature": [
    {
      "feature": "ST_Slope",
      "kind": "categorical",
      "psi": 7.06,
      "severity": "major",
      "n_ref": 617,
      "n_cur": 303,
      "n_missing_cur": 0,
      "ks_statistic": null,
      "ks_p_value": null
    }
  ],
  "prediction": {
    "model_name": "tabicl",
    "psi": 0.881,
    "severity": "major",
    "n_ref": 617,
    "n_cur": 303,
    "mean_ref": 0.518,
    "mean_cur": 0.412
  }
}
```

`per_feature` is sorted by descending PSI. `kind` is `numeric` or
`categorical`; KS fields are populated only for numerics. `severity`
follows the [ADR-014](../../../docs/adr/014-drift-monitoring.md)
cut-points: `< 0.10` stable / `0.10 - 0.25` moderate / `>= 0.25` major.

```json
  "n_cells": 16,
  "by_model": {

      "prediction_psi_mean": 1.567,
      "prediction_psi_max": 2.941

```

## Reproduce

```bash
# One-time: rebuild combined parquet + per-fold model artefacts.
uv run --project backend python backend/scripts/build_combined.py
uv run --project backend python backend/scripts/train_v1.py

# Phase-2.6 sweep (writes per_fold.json + aggregate.json + 16 dashboard PNGs):
uv run --project backend python backend/scripts/compute_drift.py
```

CI smoke (~10 s on ubuntu-latest, gitignored output):

```bash
uv run --project backend python backend/scripts/compute_drift.py --smoke
```
